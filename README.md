# Electric-Field-Simulator
This simulator visualizes the electric field generated by point charges.

## Required
- pygame

## Usage
Run the following command:
```sh
python -m simulator.main
```

or you can create an executable file to make it easy to run if you're using `.venv`.

1. create a file

inside `simulate`:
```sh
#/bin/sh
source .venv/bin/activate
python -m simulator.main
```
2. grant permission:
```sh
chmod +x simulate
```

3. run
```sh
./simulate
```
