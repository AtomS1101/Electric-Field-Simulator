# Electric-Field-Simulator
This simulator visualizes the electric field generated by point charges.

<img width="400" height=auto alt="screen" src="https://github.com/user-attachments/assets/2249ae8d-5e7b-432a-96ef-e35e2c40ac02" />

## Requirements
- Python 3.9 or later
- pygame 2.0 or later

```sh
pip install pygame
```

## Usage
Run the following command.
You can't directly run `main.py` since it uses relative paths for import.
```sh
python -m simulator.main
```

or you can create an executable file to make it easy to run if you're using `.venv`.

1. create a file

inside `simulate`:
```sh
#/bin/sh
source .venv/bin/activate
python -m simulator.main
```
2. grant permission:
```sh
chmod +x simulate
```

3. run
```sh
./simulate
```

## How to use?
1. Tap the "+" button to add a new charge.
2. Click the text box and enter the number to modify the charge.
3. Drag and drop to move each charge.
4. You can scroll to view the hidden areas.
5. You can remove the charge by entering `0`.
